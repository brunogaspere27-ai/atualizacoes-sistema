# CW Transportadora

## Visão geral

Sistema desktop (Python + CustomTkinter) para gestão logística: fretes, notas
fiscais, viagens, frota, financeiro e relatórios. Usa SQLite local com
sincronização offline-first opcional para um banco Supabase. Não é uma
aplicação web — não roda em preview do Replit; é executado localmente com
`python main.py` (requer Tcl/Tk).

Ver `README.md` para instalação, arquitetura, estrutura de pastas e
configuração (`.env` vs `configuracoes.json`).
